# NTBA0006: Early lifecycle JS interop should use a recognized interactivity check

| Default severity | Code fix |
| --- | --- |
| Warning | Yes: "Guard with `RendererInfo.IsInteractive`" |

## Why it matters

`OnInitialized`, `OnParametersSet`, and `SetParametersAsync` can run during prerendering on the server, where JavaScript is not available. JS interop called there fails and can break the render. Calls made in `OnAfterRender` or `OnAfterRenderAsync` run only after the component is interactive, so either move the call there or guard it with an interactivity check.

## What is reported

- JS interop in `OnInitialized{Async}`, `OnParametersSet{Async}`, or `SetParametersAsync` that runs before `OnAfterRender{Async}` without a recognized interactivity check.
- Recognized checks:
  - `if (RendererInfo.IsInteractive)`
  - `if (AssignedRenderMode is not null)`
  - a guard clause such as `if (!RendererInfo.IsInteractive) return;`
  - a helper method that wraps one of those checks
  - a call to a helper that performs the JS interop and is reached only through a recognized guard
- Unrelated boolean conditions do not suppress the rule.

## How to fix

Before:

```razor
@rendermode InteractiveServer

@code {
    [Inject] private IJSRuntime JS { get; set; } = default!;

    protected override async Task OnInitializedAsync()
    {
        await JS.InvokeVoidAsync("doSomething");
    }
}
```

After (manual guard clause; the code fix instead wraps the body in `if (RendererInfo.IsInteractive) { ... }`):

```razor
@rendermode InteractiveServer

@code {
    [Inject] private IJSRuntime JS { get; set; } = default!;

    protected override async Task OnInitializedAsync()
    {
        if (!RendererInfo.IsInteractive)
        {
            return;
        }

        await JS.InvokeVoidAsync("doSomething");
    }
}
```

Alternatively, move the call into `OnAfterRenderAsync(bool firstRender)`.

## Configuration

- Strict mode does not change this rule's severity. No other settings apply.

See [Configuration](README.md#configuration) for the setting syntax.

## Suppressing

In `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.NTBA0006.severity = none
```

In code:

```csharp
#pragma warning disable NTBA0006
// early lifecycle JS interop
#pragma warning restore NTBA0006
```
